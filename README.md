# E-Pharms 💊

**E-Pharms** is a web-based e-pharmacy platform that combines medicine discovery with a simple e-commerce shopping experience. Users can browse medicines, upload prescriptions, review matched medicines, add products to a cart, and place demo orders.

## Features

* 🔍 Search and filter medicines
* 📋 Prescription upload and medicine matching
* 🛒 Shopping cart with quantity management
* 💳 Demo checkout and payment options
* 📦 Order confirmation and order history
* 💊 Medicine details with stock and prescription status
* 📱 Responsive pharmacy-focused UI
* 🗄️ SQLite database for local data persistence
* ⚙️ Node.js + Express backend APIs

## Tech Stack

**Frontend:** HTML, CSS, Bootstrap, JavaScript
**Backend:** Node.js, Express.js
**Database:** SQLite
**Tools:** Git, GitHub, VS Code

## Project Workflow

**Normal Shopping**

`Browse → Search Medicine → Add to Cart → Checkout → Place Order`

**Prescription Shopping**

`Upload Prescription → Analyze → Review Medicines → Add to Cart → Checkout → Place Order`

## Getting Started

```bash
npm install
npm start
```

Open:

```text
http://localhost:3000/home.html
```

The project uses Node.js and does not require a separate database server. The SQLite database is created automatically when the application starts.

## Project Purpose

This project was developed as a practical **Computer Science project** to demonstrate concepts such as web development, REST APIs, database management, file handling, client-side storage, and e-commerce workflows.

## Disclaimer

This is an educational/demo project. Prescription matching is assistive and should not be used for medical diagnosis, dosage changes, or medicine substitution.
